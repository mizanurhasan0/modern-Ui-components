# Creative Login reference assets

The character, clothing, entrance and waiting animations, and environment originate from the public Visme form used by the supplied video:
https://forms.visme.co/formsPlayer/g7ddqxx0-untitled-project?fullPage=true

The original character is Visme casual male preset c_m_preset_03. The GLBs were decoded and gzip-compressed for local browser delivery. No third-party model decoder or remote asset requests are required at runtime. The poster is rendered from the same models.

The React form and scene integration are implemented in this project. Attribution identifies the original artwork; it does not grant an independent asset license.
